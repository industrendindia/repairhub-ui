# RepairHub UI

Frontend foundation for RepairHub built with React 19, TypeScript, Tailwind CSS, Vite, React Router, TanStack Query, Axios, React Hook Form, and Zod.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run lint`
- `npm run typecheck`

## Structure

- `src/app`: app providers and routing
- `src/features`: feature modules such as auth and future business modules
- `src/layouts`: shell layouts
- `src/lib`: API, query, storage, and utility helpers
- `src/shared`: reusable UI and cross-feature components
- `src/pages`: route-level pages without business-module ownership
